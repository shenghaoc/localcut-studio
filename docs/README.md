## What is LocalCut Studio?

A native macOS video editor: import clips, arrange them on a multi-track timeline, preview in real time, and export a finished movie — all processed locally on your Mac. It's the desktop-native version of the browser-based [LocalCut Studio](https://github.com/shenghaoc/browser-editor).
